# Solar System Simulation

## Project Overview

The Solar System Simulation is an interactive multimedia application developed using **HTML5 Canvas, CSS, and Vanilla JavaScript**. The application simulates a simplified 2D solar system where celestial bodies orbit around a central sun in real time using mathematical transformations and animation techniques.

The project demonstrates the fundamental stages of the **computer graphics pipeline**:
- Application Stage
- Geometry Stage
- Rasterization Stage

The simulation focuses on real-time rendering, object animation, user interaction, and visual effects, all implemented without external libraries or frameworks.

---

#  Objectives

The project aims to:

- Simulate planetary orbital motion using trigonometric calculations
- Demonstrate real-time animation using the HTML5 Canvas API
- Illustrate the graphics pipeline stages in a practical multimedia application
- Provide interactive controls for manipulating the simulation
- Create an engaging and visually immersive space environment

---

# Features

## Solar System Simulation
- Central sun positioned at the center of the canvas
- Multiple planets orbiting at different speeds and radii


---

## Interactive Space Environment
- Twinkling starfield background
- Radial glow effects around the sun
- Orbit path visualization
- Planet motion trails for enhanced movement perception

---

## User Interaction Features
- Pause and resume simulation
- Adjustable simulation speed
- Click-to-focus planet camera system
- Zoom and pan functionality
- Planet hover highlighting
- Dynamic planet information panel

---

## Visual Effects
- Procedural star generation
- Pulsing solar glow animation
- Depth-inspired scaling and lighting effects

---

# Technologies Used

- HTML5 Canvas API
- CSS
- Vanilla JavaScript 

No external libraries or frameworks were used in the development of this project.
